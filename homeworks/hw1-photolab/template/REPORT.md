## 2. Три вопроса

**2.1. Какое цветовое пространство выбрано для хромакея и почему? Что было бы в RGB?**

Для хромакея выбрано пространство HSV (Hue, Saturation, Value), так как оно позволяет задать диапазон объекта, устойчивый к изменению освещения. В пространстве RGB все 3 канала зависят от яркости и при изменении освещения меняются одновременно, поэтому невозможно выделение объекта простым пороговым ограничением.

**2.2. Что происходит с гистограммой при γ < 1 и при γ > 1? Куда деваются обрезанные пиксели?**

При **γ < 1** (осветление) гистограмма сдвигается вправо: тёмные пиксели становятся светлее, левая часть гистограммы «разрежается», а правая может уплотняться.
При **γ > 1** (затемнение) гистограмма сдвигается влево: светлые пиксели темнеют, правая часть разрежается, левая уплотняется.  
**Обрезанные пиксели** (clipping) теряют градации и накапливаются на границах диапазона (значения 0 или 255), что означает безвозвратную потерю деталей в тенях или светах.

**2.3. Почему CLAHE лучше `equalizeHist` на вашем фото — по числам из 1.3? Если не лучше — что измерили и почему?**

equalizeHist агрессивно растягивает контраст: среднее в тенях выросло с 4.0 до 31.8, но стандартное отклонение (шум) в тенях подскочило с 2.0 до 15.4 (в 7.5 раз!), а света ушли в пересвет (среднее 229.3).
Алгоритм CLAHE (с clip=2.0) ограничивает усиление контраста в локальных областях. В результате тени стали видны лучше (среднее выросло до 9.9), но шум вырос незначительно (σ = 4.3 против 15.4), а света остались в адекватном диапазоне (174.3), сохранив детализацию.

## 3. Где сломалось

Команда, файл, что получилось, причина, что бы помогло.

Проблема 1: При выпрямлении перспективы (rectify) окно OpenCV не помещалось на экране из-за высокого разрешения исходного фото.
Решение: В функции pick_corners параметр масштаба 1200.0 был уменьшен до 600.0, что позволило комфортно кликнуть по 4 углам.
Проблема 2: При хромакее маска выделяла фон (стену), а не объект (плакат).
Решение: В функции chroma_key добавлена инверсия маски (mask_float = 255.0 - comp_mask.astype(np.float32)), чтобы белым цветом отмечался именно целевой объект, а фон замещался.

## 4. Команды

Всё, что лежит в `out/`, получено этими командами (скопируйте из консоли):

```bash
# 1. Гамма-коррекция
python photolab.py gamma data/dark.jpg --gamma 0.5 -o out/gamma_05.png --hist out/hist_gamma_05.png
python photolab.py gamma data/dark.jpg --gamma 1.5 -o out/gamma_15.png --hist out/hist_gamma_15.png
python photolab.py gamma data/dark.jpg --gamma 2.0 -o out/gamma_20.png --hist out/hist_gamma_20.png

# 2. Баланс белого
python photolab.py wb data/bright.jpg --method grey-world -o out/wb_grey.png --hist out/hist_wb_grey.png
python photolab.py wb data/bright.jpg --method white-patch --percentile 99.0 -o out/wb_patch.png --hist out/hist_wb_patch.png

# 3. CLAHE
python photolab.py clahe data/dark.jpg --clip 2.0 --tiles 8 -o out/clahe.png --compare out/compare_clahe.png --hist out/hist_clahe.png

# 4. Хромакей (с пробой цвета со стены и инверсией маски в коде)
python photolab.py chromakey data/object.jpg --bg data/bg.jpg --sample 50,50,100,100 -o out/chroma.png --mask out/mask.png

# 5. Геометрия
python photolab.py rotate data/poster.jpg --deg 30 -o out/rotated_30.png
python photolab.py resize data/poster.jpg --scale 0.5 --method area --report -o out/resized_05.png
python photolab.py resize data/poster.jpg --scale 0.25 --method area --report -o out/resized_025.png
python photolab.py rectify data/poster.jpg --clicks --size 600x800 -o out/rectified.png

# 6. Контактный лист
python photolab.py sheet out/gamma_15.png out/wb_grey.png out/clahe.png out/chroma.png out/resized_05.png out/rectified.png --cols 3 -o out/sheet.png
```
